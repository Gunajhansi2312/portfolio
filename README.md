# Guna Jhansi — Portfolio

A responsive dark-theme portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — website content and sections
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current year
- `assets/` — place your resume PDF here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Replace `YOUR_GITHUB_USERNAME` with your GitHub username.
3. Add your resume PDF at `assets/Guna_Jhansi_Resume.pdf` (create the `assets` folder if needed).
4. Check all project descriptions and update them to reflect work you can accurately demonstrate.
5. Add real project repository/demo links when available.
6. Do not upload confidential employer/client code, personal data, or production information.

## Preview locally
Open `index.html` in a browser. For a local development server, use the Live Server extension in Visual Studio Code.

## Publish free with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the deployment to finish. Your site will be available at `https://yourusername.github.io`.

If you use a repository with a different name, the URL will usually be `https://yourusername.github.io/repository-name/`.

## Notes
- The site uses Google Fonts when online and falls back to system fonts.
- The email link uses `mailto:` and opens the visitor's email app; it is not a server-backed contact form.
